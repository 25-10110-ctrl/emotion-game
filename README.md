# 🌈 오늘 내 마음은 어떤 색? (Emotion Game)

유아(만 2~6세)를 위한 **감정 공감 & 정서 발달 인터랙티브 웹 미니게임**입니다.  
아이들이 동물 친구들의 다양한 감정(슬픔, 화남, 무서움, 외로움, 눈물)을 이해하고, 능동적으로 공감과 위로 행동을 실천하며 긍정적인 정서 치유를 경험할 수 있도록 돕습니다.

---

## 🎮 게임 특징 및 플레이 방법

### 1️⃣ 1단계: 감정 인지 및 공감하기
- 화면에 등장하는 동물 친구의 표정과 상황을 관찰합니다.
- *"토끼가 왜 속상할까요?"*, *"곰이 왜 화가 났을까요?"* 와 같은 질문에 대해 아이가 원인을 생각하고 알맞은 선택지를 고릅니다.

### 2️⃣ 2단계: 위로 행동 실천하기
- 안아주기(🤗), 손 잡기(🤝), 선물하기(🍦/🧸/🌸), 함께 있어주기(🌙) 등의 위로 버튼을 터치합니다.
- 터치할 때마다 하트 게이지가 채워지고, 친구의 표정이 점차 편안해집니다.

### 3️⃣ 3단계: 긍정 정서 회복 & 축하
- 하트가 모두 채워지면 캐릭터가 활짝 웃으며 기뻐하고 춤을 춥니다.
- 차갑거나 불안했던 배경 색상이 따뜻하고 화사한 무지개빛으로 변화합니다.

---

## 🐾 등장하는 동물 친구들과 감정

| 캐릭터 | 감정 상태 | 원인 상황 | 위로 행동 |
| :---: | :---: | :--- | :--- |
| 🐰 **토끼** | 😢 속상함 | 아이스크림을 바닥에 떨어뜨렸어요 | 안아주기, 새 아이스크림 주기, 토닥이기 |
| 🐻 **곰** | 😠 화남 | 친구가 장난감을 빼앗아 갔어요 | 손잡기, 양보하고 나누기, 함께 놀기 |
| 🐱 **고양이** | 😨 무서움 | 밖에서 천둥번개가 요란하게 쳐요 | 꼭 안아주기, 곁에 있어주기, 노래 부르기 |
| 🐶 **강아지** | 🥺 외로움 | 아무도 같이 놀아주지 않아 혼자예요 | 먼저 다가가 말 걸기, 손잡기, 풍선 주기 |
| 🐥 **병아리** | 😭 슬픔/울음 | 엄마가 너무 보고 싶어요 | 따뜻하게 안아주기, 해바라기 주기, 뽀뽀 |

## 🛠️ 기술적 특징

- **단일 파일 독립 실행**: 외부 이미지나 라이브러리 설치 없이 [`emotion-game.html`](emotion-game.html) 파일 하나로 즉시 실행됩니다.
- **순수 CSS 벡터 아트**: 귀, 눈, 코, 입, 볼터치, 눈물, 땀방울 등 캐릭터의 표정 변화가 CSS 애니메이션으로 부드럽게 구현되어 있습니다.
- **Web Speech API (TTS)**: 전문 성우처럼 다정하고 친근한 톤(피치 및 속도 조절)의 한국어 음성 안내가 전체 과정에 걸쳐 제공됩니다.
- **모바일/태블릿 최적화**: 터치 제스처에 최적화된 큰 버튼과 직관적인 UI로 구성되어 유아가 혼자서도 쉽게 조작할 수 있습니다.
