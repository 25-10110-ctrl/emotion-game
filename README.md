# 🎈 유아 놀이 게임 모음 (Kids Web Games)

유아(만 2~5세)를 위한 귀엽고 유익한 인터랙티브 웹 미니게임 컬렉션입니다.  
별도의 설치 없이 브라우저에서 바로 즐길 수 있습니다.

---

## 🎮 포함된 미니게임

### 1. 🐾 동물 소리 맞추기 게임 (`animal-sound-game.html`)
- **특징**: "누구의 소리일까요?" 음성 안내와 함께 동물 고유의 울음소리를 듣고 정답 동물을 터치하는 청각 인지 게임
- **등장 동물**: 강아지(멍멍), 고양이(야옹), 소(음메), 오리(꽥꽥), 돼지(꿀꿀), 개구리(개굴개굴)
- **모드**: 🎮 퀴즈 게임 모드 / 🔊 자유 탐험 모드

### 2. 🔍 숨은 동물 찾기 게임 (`hidden-animal-game.html`)
- **특징**: 풀숲, 나무 뒤, 상자 안, 바위 뒤에 살짝 삐져나온 꼬리나 귀를 발견하고 터치하면 동물이 쏙 튀어나오는 탐색 놀이
- **CSS 아트 그래픽**: 자연 풍경과 캐릭터를 순수 CSS 애니메이션으로 표현

### 3. 🌈 오늘 내 마음은 어떤 색? (`emotion-game.html`)
- **특징**: 속상함, 화남, 무서움, 외로움, 슬픔을 느끼는 동물 친구들의 상황을 공감하고(질문 선택), 안아주기와 선물을 통해 하트를 채워주며 감정을 풀어주는 정서 발달 힐링 게임
- **실시간 표정 변화**: 아이의 위로 터치에 따라 캐릭터의 표정이 부드럽게 밝아짐

---

## 🛠️ 기술 스택
- **HTML5 / CSS3 / Vanilla JavaScript**
- **Web Speech API (SpeechSynthesis)**: 한국어 자연스러운 음성 안내 지원
- 모바일/태블릿 터치 환경 완전 지원 (Responsive & Touch-Friendly)
